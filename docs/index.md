# The Unopened Scape

**The Unopened Escape** é um minijogo cooperativo e assimétrico de horror psicológico, desenvolvido para óculos de Realidade Virtual (**Meta Quest**) e integrado a uma interface mobile para smartphones.

O projeto faz parte da disciplina **Tópicos Especiais em Jogos Digitais – Turma 1 (2026/1)**, do curso de Engenharia de Software da **Universidade de Brasília (UnB/FGA)**.

## Tecnologias Utilizadas

| Tecnologia | Descrição |
| :--- | :--- |
| **Unity Engine** | Motor gráfico utilizado para simulação de física, renderização de materiais e controle de iluminação de horror. |
| **C#** | Programação orientada a componentes e tratamento lógico das mecânicas internas de validação. |
| **Figma** | Ferramenta gráfica aplicada na identidade visual, paleta de cores e diagramação dos manuais digitais e impressos. |
